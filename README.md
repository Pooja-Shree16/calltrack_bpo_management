# 📞 CallTrack – BPO Management System

CallTrack is a web-based **BPO Management System** developed to manage users, BPO operations, and administrative activities in one platform.

## 🚀 Features

* 👤 User Signup & Login
* 🏢 BPO Signup & Login
* 👨‍💼 Admin Login & Dashboard
* 📊 User & BPO Dashboards
* 🔥 Firebase Authentication & Firestore
* 🤖 AI-based Entity Detection
* 🎨 Responsive and Modern UI

## 🛠️ Technologies Used

* Next.js
* React
* TypeScript
* Tailwind CSS
* Firebase
* Firestore
* Genkit

## ▶️ How to Run

```bash
npm install
npm run dev
```

Then open:

```text
http://localhost:3000
```
